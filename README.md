# OtherSkills — 顧問式銷售智能體工具組

以「顧問式銷售法（TUP）」為底層邏輯，搭配「LIFO 客群行為風格分析」，
建構可跨產業部署的 AI 銷售流程架構師。

---

## 工具組架構

```
skills/
├── industry-sales-builder/   ← 上層：跨產業銷售流程架構師（主入口）
├── consultative-sales/       ← 底層引擎：顧問式銷售五步驟
└── customer-profiling/       ← 底層引擎：LIFO 客群風格診斷
```

三個 Skill 形成鏈路，`industry-sales-builder` 為主入口，另外兩個為知識引擎。

---

## 快速使用

### 建構任一產業的銷售流程
```
/industry-sales-builder

產業：保險
產品：利變型終身壽險
理想客戶：35-50歲、有家庭、自營業主
```

輸出：完整六模組銷售流程 + 一頁備忘卡

---

### 顧問式銷售教練（單獨使用）
```
/consultative-sales

我的產品是 SaaS 人資系統，客戶說太貴了，怎麼應對？
```

模式：分析模式 / 話術設計模式 / 教練模式 / 檢核模式

---

### 客群風格診斷（單獨使用）
```
/customer-profiling

我的客戶是一家製造業老闆，開會習慣主導決策、被拒絕會直接反擊
請幫我診斷他的風格並給我溝通策略
```

模式：問卷模式（18題 LIFO）/ 觀察推斷模式

## 三個 Skill 說明

### `/industry-sales-builder`
**用途**：輸入產業 + 產品 + 理想客戶，輸出可直接使用的完整銷售流程。

**輸出六模組**：
1. 銷售定位（三問）
2. 客群 LIFO 風格 × 溝通策略
3. 需求確認問題庫（20條）
4. 特色→效益轉換清單
5. 疑義處理庫（Top 5）
6. 成交→轉介紹完整路徑

**內建產業知識庫**：金融/保險、房地產、教育/培訓、醫療/保健品、B2B企業服務、SaaS/科技、美妝保健、傳直銷

---

### `/consultative-sales`
**用途**：顧問式銷售法教練，適用銷售話術設計、情境分析、疑義處理、成交布局。

**底層邏輯**：
- 銷售三問（為何買 / 為何跟你買 / 為何持續買）
- 五步驟流程：尋找顧客 → 確認需求 → 提供方案 → 疑義處理 → 成交
- 特色 vs. 效益轉換公式
- 物超所值心理公式（所得 ÷ 所付 > 1）
- 情 → 理 → 法底層心法

**來源**：TUP 顧問式銷售法課程逐字稿

---

### `/customer-profiling`
**用途**：LIFO 客群行為風格診斷，輸出對應溝通策略與雷區提醒。

**四種風格**：
| 風格 | 代稱 | 核心訴求 |
|------|------|---------|
| 卓越 SG | 無尾熊 / 支持者 | 使命感、公益、被肯定 |
| 行動 CT | 老虎 / 掌控者 | 效率、挑戰、主導感 |
| 理性 CH | 貓頭鷹 / 持穩者 | 數據、案例、低風險 |
| 和諧 AD | 孔雀 / 順應者 | 熱鬧、受歡迎、氛圍 |

**兩種診斷模式**：18題問卷 / 觀察線索快速推斷

**來源**：LIFO 個人行為風格分析簡測表（2018）

## 核心銷售哲學

> 銷售 = 人性心理學，不是買賣行為。
> 成交是布局的結果，從第一個接觸點就開始決定。
> 你的角色是「顧問」而非「業務員」。
