# otherskills

收集各種 skill 的 repo。

## 資料夾結構規則

**所有新的 skill 都必須開一個新的資料夾再存放，不可以直接存在 repo 根目錄。**

- 每個 skill（或 skill 集合）都放在自己的資料夾裡，例如 `slavingia-skills/`。
- repo 根目錄只放 README 和各個 skill 資料夾，不放個別的 skill 檔案。
- 資料夾名稱請使用能清楚辨識來源或用途的名字（小寫、以 `-` 連接）。

> Rule (English): Every new skill must be saved inside its own new folder. Do not save skill files directly in the repository root.
